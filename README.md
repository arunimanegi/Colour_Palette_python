# ColourPalette Generator Python

A simple Python tool to generate complementary color schemes based on a selected base color. This program takes a HEX color code as input and outputs its complementary color. It's a great utility for designers, developers, or anyone exploring color combinations for their projects!

---

## 🌟 Features
- Accepts a base color in HEX format (e.g., `#3498db`).
- Generates a complementary color using the HLS (Hue, Lightness, Saturation) color model.
- Outputs the result in HEX format, ready for use in design or code.

---

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your system.

### Installation
No additional libraries are required for this project as it uses Python's built-in `colorsys` module.

---

## 🛠️ Usage

1. Clone the repository or download the script file:
   ```bash
   git clone https://github.com/your-username/color-palette.git
   cd color-palette
   ```

2. Run the script:
   ```bash
   python color_palette.py
   ```

3. Enter a base color in HEX format when prompted:
   ```text
   Enter a base color in HEX format (e.g., #3498db): #3498db
   ```

4. The script will output the complementary color:
   ```text
   Base Color: #3498db
   Complementary Color: #db6434
   ```
